# Bim Infotech

Mono repo for all things related to Bim infotech work

## Folders

| Folder       | Detail                                        |
| ------------ | --------------------------------------------- |
| mobileapp    | Flutter app - employee centric daily checkins |
| hono-backend | Contains hono app, docker and database setup  |
| docs         | Docs for the schema                           |
| admin-corner | NextJS app to for admin activities            |

## Softwares required

- Docker
- VS Code
- Bruno
- NodeJS > v22
- Flutter SDK
- Android emulator

## Setup for local

- Run the backend
  - `cd hono-backend` to go into the backend directory
  - `npm run stack:dev`
- For running frontend for `admin-corner` locally, run `npm install` and then `npm run dev`
